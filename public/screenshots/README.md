# App Screenshots

Add screenshots of the RepRadar app here to display on the landing page:

- `dashboard.png` - Dashboard view (call cards, metrics, score chart)
- `call-detail.png` - Call detail page (score, key moments, improvement tips)
- `leaderboard.png` - Team leaderboard
- `team.png` - Team management page

**How to capture:**
1. Run `cd sales-call-analyzer && npm start`
2. Log in and navigate to each screen
3. Capture at 1280×800 or 1440×900 (full viewport)
4. Save files to this folder

Until screenshots are added, the landing page shows styled placeholders.
